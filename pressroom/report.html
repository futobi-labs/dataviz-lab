Reading it

The blocks are the hierarchy. Harbor holds the one number the business asks about, Marigold holds the year, Persimmon holds the clock, and the paper tiles carry the categorical charts, because the eight data inks were checked against paper and nothing else. On a colored block every mark is printed in that block's own ink, one color per tile, the way a two-color job would be. Selection never repaints anything: what you didn't pick turns to halftone or fades, so the eye still finds it.

Things to find: June is the fortnight of throttled capacity, nine late nights and the tallest columns of the year. The dense spring screen in Silver and Gold is the orphaned CRM accounts; pick CRM and it stays while most of the rest goes pale. December's dark cells are volume tests tripping on Black Friday, and October's Bronze row is CRM freshness tests during the vendor's rate limits.

Building it in Power BI

The page is 1280 by 720, twelve columns by six rows, 16px margin and 12px gutters. Positions below are what you type into Format > General > Properties. The texture is the one thing Power BI can't draw, so it comes in as a picture: press Canvas only above, screenshot the frame at 1280 by 720, or use the background JPEGs in the repo, and set it as the page's Canvas background with transparency 0. Then every visual sits on it with its background off, which the theme already does.

Cross-highlight, not cross-filter

In Format > Edit interactions, set the column chart and the halftone matrix to Highlight and the hero cards to Filter. Highlight keeps the axis and the shape of the year and shows the selection inside it, which is what this page does with halftone. Deneb visuals take part when you switch on cross-highlight and cross-filter in their settings and test the selection fields in the spec.

Measures behind the tiles

On-time nights =
CALCULATE ( COUNTROWS ( Runs ), Runs[SLA met] = TRUE () )

Median Gold finish =
FORMAT ( TIME ( 0, MEDIAN ( Runs[Gold finish minutes] ), 0 ), "hh:mm" )

Issues =
CALCULATE ( COUNTROWS ( TestResults ), TestResults[Outcome] IN { "warn", "fail" } )

Issues per night =
DIVIDE ( [Issues], DISTINCTCOUNT ( TestResults[Night] ) )
